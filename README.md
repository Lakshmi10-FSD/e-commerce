#  Mini E-Commerce Website:

A simple and responsive **Mini E-Commerce Website** built using **HTML, Tailwind CSS, and JavaScript**. This project allows users to browse products, add items to the cart, and view a checkout page with total pricing.

##  Technologies Used:

* **HTML** – Structure
* **Tailwind CSS** – Styling & responsive design
* **JavaScript** – Functionality (cart, DOM, logic)
* **LocalStorage** – Store cart data

##  How It Works:

1. User browses products
2. Clicks **Add to Cart**
3. Items are stored in cart (localStorage)
4. Cart page displays selected items
5. Total price is calculated dynamically

##  Product Categories:

* 👕 Clothing (T-Shirts, Hoodies)
* 👟 Shoes (Casual, Sports, Formal)
* ⌚ Watches (Elegant, Sport, Luxury)
* 👜 Bags (Handbags, Sling, Backpack)

## ▶️ How to Run:

1. Open **Notepad / VS Code**
2. Save files (`index.html`, `script.js`, etc.)
3. Double-click `index.html`
4. Open in browser
